# Messaggio di invito

Ciao,

sto preparando una beta chiusa di OMISSIS, un'app desktop che aiuta a rimuovere localmente i dati personali dai documenti prima di usarli con strumenti di intelligenza artificiale.

Ti chiederei una prova di circa 45-60 minuti nell'arco di due settimane. Riceverai tre documenti interamente inventati e una guida breve. Mi interessa capire se l'installazione è semplice, se il risultato è affidabile e se qualche passaggio crea dubbi.

Puoi anche provare un tuo documento, ma deve restare sul tuo computer: non dovrai inviare file originali, testi reali, password o File di ripristino. Nel feedback basta descrivere il tipo di problema oppure ricrearlo con dati inventati.

Se partecipi, ti assegnerò un codice tester e ti manderò build, hash di verifica, casi di prova e scheda feedback.
